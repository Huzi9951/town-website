# Visit Nerul

A hometown page in a late-90s / early-2000s web style: big type, stacked photos, and short notes. Three stops — Wonders Park, Flamingo Point, and the food spots (Oho shawarma and Grace parathas).

The page itself is in `Scrim-s04h5q2/`. It started as a Scrimba layout exercise and became a guide to Nerul.

## Run

```bash
cd Scrim-s04h5q2
npm install
npm start
```

Open `index.html` and `styles.css` if you want to read the layout without installing anything.
